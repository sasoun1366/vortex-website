## ۲) کارهایی که باید خودت انجام بدهی (۵ دقیقه)

فایل `assets/js/products.js` را باز کن و بالای آن، بخش `config` را ویرایش کن:

```js
config: {
  whatsapp : "989120000000",     // ← شماره واتساپ با کد کشور، بدون + و بدون صفر اول
  telegram : "VortexGearBot",    // ← یوزرنیم بات تلگرام بدون @
  instagram: "vortex.gear",      // ← پیج اینستاگرام بدون @
  email    : "order@vortex.gear",
  phone    : "+98 912 000 0000",
  shippingCost : 180000,         // هزینه ارسال (۰ بگذار = رایگان)
  freeShipOver : 3000000         // ارسال رایگان از این مبلغ به بالا
}
```

> همین حالا این‌ها **مقدار نمونه** هستند. تا عوض نشوند، دکمه‌های واتساپ/تلگرام به شماره واقعی وصل نمی‌شوند.

## ۳) افزودن / ویرایش محصول

در همان فایل، آرایه `products` را ویرایش کن. برای هر محصول:

```js
{
  id: "vx-tee-002",                      // یکتا باشد
  cat: "apparel",                        // apparel | accessory | gear
  img: "assets/img/tee.jpg",             // عکس محصول
  price: 1480000,                        // قیمت (تومان) بدون کاما
  oldPrice: 1850000,                     // قیمت قبل از تخفیف — 0 = بدون تخفیف
  featured: true,                        // در صفحه اصلی نمایش داده شود؟ (۴ محصول اول)
  badge: { fa: "پرفروش", en: "Best seller" },
  name: { fa: "اسم فارسی", en: "English name" },
  desc: { fa: "توضیح فارسی", en: "English description" },
  sizes: ["S","M","L","XL","XXL"]        // اگر سایز ندارد: []
}
```

محصولاتی که سایز دارند، موقع «افزودن به سبد» اول مودال انتخاب سایز باز می‌کنند (مثل رفتار فروشگاه‌های واقعی).

## ۴) جایگزینی عکس محصولات

عکس‌ها در `assets/img/` هستند. کافی است عکس جدید خودت را با **همان نام** جایگزین کنی:
`tee.jpg` · `crop-tee.jpg` · `wrist-wraps.jpg` · `liquid-chalk.jpg` · `keychain.jpg` · `hero.jpg`
(برای عکس جدید نام بگذاری، فقط مسیر `img` در `products.js` را هم عوض کن.)

پیشنهاد: عکس‌های مربعی یا ۴:۳، حداقل ۱۰۰۰ پیکسل، پس‌زمینه تیره (مثل عکس‌های فعلی) — با تم سایت یکدست می‌شوند.

## ۵) خروجی گرفتن و آنلاین کردن

| روش | کار |

## ۶) روند سفارش (چرا درگاه لازم نیست)

1. مشتری محصولات را به سبد اضافه می‌کند (سایز + تعداد).
2. اگر بخواهد، «اطلاعات تحویل» را در سبد پر می‌کند (در مرورگر خودش ذخیره می‌شود).
3. یکی از دو دکمه:
   - **ثبت سفارش در واتساپ** → واتساپ با متن سفارش آماده باز می‌شود (`wa.me`).
   - **ثبت سفارش در تلگرام** → متن سفارش خودکار کپی می‌شود و چت بات باز می‌شود.
4. سفارش با همان پیام ثبت می‌شود؛ شما موجودی و روش پرداخت را تأیید می‌کنید.

نمونه متن تولیدشده:

```

———————————
• ۱ × تی‌شرت تمرین ورتکس — انتخاب سایز: L — ۱٬۴۸۰٬۰۰۰ تومان
———————————
جمع کالاها: ۱٬۴۸۰٬۰۰۰ تومان
ارسال: ۱۸۰٬۰۰۰ تومان
مبلغ نهایی: ۱٬۶۶۰٬۰۰۰ تومان
———————————
نام و نام خانوادگی: علی رضایی
شماره تماس: 09121234567
شهر و آدرس: تهران، سعادت‌آباد
```

### بات تلگرام (اختیاری، برای مرحله بعد)
اگر بخواهی سفارش‌ها در بات هم خودکار ثبت شوند، یک بات با `@BotFather` بساز و یک وب‌هوک کوچک (مثلاً روی Cloudflare Workers یا یک فایل PHP) بگیر تا پیام کاربر مستقیم در بات ذخیره/فوروارد شود. فعلاً مسیر «کپی متن + ارسال به بات» بدون هیچ سروری کار می‌کند.

## ۷) امکان‌های دیگر (در ادامه می‌توان اضافه کرد)

- صفحه اختصاصی هر محصول (`product.html?id=...`) + گالری چند عکسی
- افزودن درگاه پرداخت (زرین‌پال / آیدی‌پی) و صفحه تسویه حساب
- کد تخفیف، راهنمای سایز، پیگیری سفارش
- وبلاگ/مجله ورتکس برای SEO
- فرم عضویت در خبرنامه

## ۸) نکات فنی

- **دوزبانه:** دکمه FA/EN در هدر. انتخاب زبان در `localStorage` ذخیره می‌شود و جهت صفحه خودکار RTL/LTR می‌شود.
- **بدون وابستگی خارجی:** فونت‌ها لوکال هستند؛ سایت آفلاین هم درست نمایش داده می‌شود.
- **ریسپانسیو:** تست‌شده روی ۳۹۰px (موبایل) تا ۱۴۴۰px دسکتاپ؛ بدون سرریز افقی.
- **سبک و سریع:** کل سایت ~۱.۵ مگابایت با تصاویر؛ بدون فریم‌ورک.
- **دسترس‌پذیری:** ناوبری با کیبورد، `aria-label` روی دکمه‌ها، احترام به `prefers-reduced-motion`.

### دیپلوی خودکار (هر push = انتشار خودکار)
1. کد را روی ریپوی گیت‌هاب بگذار (شاخهٔ `main`)
2. در ریپو: **Settings → Secrets and variables → Actions** دو سکرت بساز:
   - `CLOUDFLARE_API_TOKEN` — توکنی با دسترسی `Account → Workers Scripts → Edit`
   - `CLOUDFLARE_ACCOUNT_ID` — `1a8b7576fba621e1a576b5f02009560f`
   (یا خودکار: `GITHUB_TOKEN=xxx REPO=owner/repo CF_API_TOKEN=xxx CF_ACCOUNT_ID=xxx python3 scripts/set-gh-secrets.py`)
3. تمام — ورک‌فلوی `.github/workflows/deploy.yml` از این به بعد با هر `git push` سایت را آپدیت می‌کند.

### وصل کردن دامنهٔ vortexgear.ir
دامنه الان روی کلودفلر نیست (اکانت فعلاً `luyava.com` و `luyavan8n.com` را دارد):

1. داشبورد کلودفلر → **Add a site** → `vortexgear.ir` → پلن **Free** (پلن رایگان برای این سایت کافی است)
2. کلودفلر دو نیم‌سرور می‌دهد؛ در پنل ثبت‌کنندهٔ دامنه (ایرنیک/میهن‌وب/…) جایگزین نیم‌سرورهای فعلی کن
3. بعد از فعال شدن دامنه: **Workers & Pages → vortexgear → Settings → Domains & Routes → Add → Custom domain** → `vortexgear.ir`
   (و در صورت تمایل `www.vortexgear.ir` را هم اضافه کن)
4. SSL خودکار فعال می‌شود؛ کمتر از چند دقیقه.

> نکته دربارهٔ ایران: گاهی `*.workers.dev` برای بعضی کاربران داخلی فیلتر است. با دامنهٔ اختصاصی `vortexgear.ir` (که روی کلودفلر است) سایت بدون مشکل باز می‌شود — این مهم‌ترین دلیل وصل کردن دامنه است.

## ۱۰) اتصال سایت به بات فروشگاه تلگرام ✅ فعال است

فروشگاه حالا فقط متن کپی نمی‌کند؛ **سفارش مستقیم در بات تلگرام ثبت می‌شود** و پیامش برای مدیر می‌آید.

| مورد | مقدار |
|---|---|
| بات | **@VortexGearBot** — https://t.me/VortexGearBot |
| چت دریافت سفارش | ۵۰۳۴۶۸۹۸۵۹ (چت شخصی مدیر) — در سکرت `OWNER_CHAT_ID` |
| وب‌هوک | `https://vortexgear.s-photography1987.workers.dev/api/tg/webhook` ✅ ثبت‌شده |
| سکرت‌ها | `BOT_TOKEN` · `OWNER_CHAT_ID` · `WEBHOOK_SECRET` (هر سه روی Cloudflare، رمزنگاری‌شده) |
| تست واقعی | سفارش `VX-261006-3758` از سایت زنده → تحویل در چت مدیر ✅ |

### تغییر مقصد سفارش‌ها به یک گروه (اختیاری، برای تیم فروش)
```bash
# ۱) بات را عضو گروه کن و یک پیام در گروه بزن
# ۲) شناسه گروه (عدد منفی) را از getUpdates بگیر، سپس:
printf '%s' "-1001234567890" | npx wrangler secret put OWNER_CHAT_ID && npx wrangler deploy
```
> دکمه‌های ✅/❌ روی پیام سفارش در گروه هم کار می‌کنند.

### چطور کار می‌کند
```
مشتری سبد می‌بندد → دکمه «ثبت سفارش در تلگرام»
        ↓  POST /api/order  (همان Cloudflare Worker، بدون سرور اضافه)
Worker سفارش را اعتبارسنجی می‌کند و یک کد می‌سازد: VX-260615-4821
        ↓
۱) پیام کامل سفارش ← چت/گروه فروشگاه تو  (با دکمه‌های ✅ تأیید موجودی / ❌ ناموجود)
۲) پیام «سفارش شما ثبت شد + کد سفارش» ← خودِ مشتری در تلگرام
۳) اگر سرور در دسترس نبود → سایت خودکار به حالت قبلی (کپی متن + باز کردن بات) برمی‌گردد
```

### داخل بات (`t.me/<یوزرنیم بات>`)
| دستور / دکمه | کار |
|---|---|
| `/start` | خوش‌آمد + دکمهٔ **🛒 ورود به فروشگاه** (باز شدن سایت داخل خود تلگرام) |
| `/shop` | همان فروشگاه |
| `/id` | شناسهٔ چت را نشان می‌دهد (برای ست کردن `OWNER_CHAT_ID`) |
| هر پیام دیگر | برای تو فوروارد می‌شود و به مشتری تأیید دریافت ارسال می‌شود |
| دکمه‌های تأیید/ناموجود | روی پیام سفارش؛ بعد از زدن، دکمه‌ها قفل می‌شوند |

### سایت داخل تلگرام (Mini App)
`telegram-web-app.js` به همهٔ صفحات اضافه شد: سایت داخل بات تمام‌صفحه باز می‌شود، **نام کاربر خودکار پر می‌شود** و پیام سفارش با نشان «از تلگرام + یوزرنیم» برای تو می‌آید. صحت داده‌های کاربر با `initData` سمت سرور بررسی می‌شود (کسی نمی‌تواند خودش را جای دیگری جا بزند).

### سه سکرت (مقدارها فقط روی Cloudflare ذخیره می‌شوند، نه در کد) — ✅ ست شده
| نام | مقدار | از کجا |
|---|---|---|
| `BOT_TOKEN` | توکن بات فروشگاه | پیام `@BotFather` → `/mybots` → API Token |
| `OWNER_CHAT_ID` | چت یا گروهی که سفارش‌ها می‌رود | داخل بات `/id` بزن، یا از `@userinfobot` |
| `WEBHOOK_SECRET` | یک رشتهٔ تصادفی | `openssl rand -hex 24` |

یک دستور، همه‌کاره:
```bash
BOT_TOKEN="123:ABC" CLOUDFLARE_API_TOKEN="xxx" OWNER_CHAT_ID="123456" \
  bash scripts/setup-telegram.sh
```
این اسکریپت: توکن را بررسی می‌کند، **وب‌هوک** را با سکرت ثبت می‌کند، دستورهای بات را ست می‌کند، سکرت‌ها را روی Cloudflare می‌نویسد و سایت را منتشر می‌کند.

### اندپوینت‌ها
| مسیر | کار |
|---|---|
| `POST /api/order` | ثبت سفارش از سایت → تلگرام |
| `POST /api/tg/webhook` | دریافت آپدیت‌های بات (توسط تلگرام صدا زده می‌شود) |
| `GET /api/health` | وضعیت: `{bot, owner, webhook}` |

### بعداً اگر خواستی
- **پنل مدیریت سفارش‌ها:** مقدار `ADMIN_URL` را به‌عنوان یک متغیر (`wrangler.jsonc → vars`) بگذار؛ دکمه «🛠 پنل مدیریت» به پیام سفارش اضافه می‌شود.
- **ذخیرهٔ سفارش‌ها در دیتابیس:** Cloudflare D1 (رایگان) — سفارش‌ها با همان کد قابل جست‌وجو می‌شوند.
- **پرداخت:** کارت‌به‌کارت یا اتصال درگاه (زرین‌پال) در همان پیام سفارش.

### 🌐 دامنه vortexgear.ir (ثبت‌شده در ایرنیک)

**قدم ۱ — افزودن دامنه به کلودفلر (خودت، ۲ دقیقه)**
1. داشبورد کلودفلر → **Add a site** (بالای صفحه) → `vortexgear.ir` → پلن **Free**
2. کلودفلر صفحه‌ای نشان می‌دهد با **دو نیم‌سرور**؛ آن دو را کپی کن (مثلاً `alina.ns.cloudflare.com` و `walt.ns.cloudflare.com`)

**قدم ۲ — تغییر نیم‌سرورها در ایرنیک**
1. برو به **https://www.nic.ir/Login** و وارد حساب ایرنیک خودت شو
2. منوی **دامنه‌ها → دامنه‌های من** → روی دامنهٔ `vortexgear.ir` کلیک کن
3. گزینهٔ **«سامانهٔ نام دامنه (DNS)»** یا **«ویرایش ردیف‌های کارگزاری نام و میزبانی دامنه»** را باز کن
4. دو نیم‌سرور فعلی را پاک کن و **دو نیم‌سرور کلودفلر** را در ردیف ۱ و ۲ بنویس
5. **پاسخ سؤال امنیتی (Secret Answer)** را وارد کن — بدون آن ایرنیک تغییرات را ذخیره نمی‌کند
6. دکمهٔ **«تغییر نیم‌سرور»** را بزن

> اگر از طریق کارگزار (میهن‌وب، نت‌افراز، …) دامنه را مدیریت می‌کنی: پنل کاربری → دامنه‌ها → مدیریت دامنه → **مدیریت NameServer** و همان دو نیم‌سرور را وارد کن.

**قدم ۳ — فعال شدن**
کلودفلر معمولاً بین چند دقیقه تا چند ساعت دامنه را Active می‌کند (ایمیل تأیید می‌فرستد).
بعد از Active شدن، بگو تا من با API این دو کار را انجام دهم:
- اتصال `vortexgear.ir` و `www.vortexgear.ir` به Worker فروشگاه
- بررسی SSL، ریدایرکت www و تست اندپوینت‌ها روی دامنهٔ اصلی

> آدرس‌های `canonical` و `og:` در همهٔ صفحات + `robots.txt` و `sitemap.xml` از قبل روی `https://vortexgear.ir` تنظیم شده‌اند ✅
